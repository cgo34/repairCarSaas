# Instructions pour Claude Code

## Git — workflow obligatoire

1. Faire les modifications de code
2. **Attendre la vérification de l'utilisateur** (ne jamais commiter automatiquement)
3. Demander : "Tu veux qu'on commit ?"
4. Après confirmation : commiter
5. Demander : "Tu veux qu'on push ?"
6. Après confirmation : pusher

Ne jamais enchaîner commit + push dans la même réponse sans validation intermédiaire.
